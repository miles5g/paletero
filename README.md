# El Paletero

## Vision
A gritty, 3D urban survival prototype built in Godot 4.x focused on physics-based vending mechanics and PS2-era aesthetics.

## Tech Stack
- Godot 4.x (Forward+)
- GDScript
- Cursor/Gemini AI-assisted workflow

## Current Features
- Physics-based cart hitching (using `Generic6DOFJoint3D`)
- Anisotropic lateral friction
- PS2-style volumetric fog/lighting
- Custom WASD/Action input mapping

## Run Instructions
1. Open the project in Godot 4.x.
2. Open `world.tscn`.
3. Press Play Scene.

## Controls
- `WASD`: Move
- `E`: Grab/Release cart
- `Shift`: Sprint
